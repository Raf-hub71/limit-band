# Limit-Leiste (limit-band)
Zeigt über dem Eingabefeld das 5-Stunden-Limit und das Wochenlimit als Balken mit Farbverlauf von grün bis rot, mit Prozentzahl und Zeit bis zum Zurücksetzen.

Installation in der Claude-Desktop-App: Plus neben dem Eingabefeld, Plugins, Marketplace hinzufügen, Pfad dieses Ordners eintragen, dann Plugin "limit-band" hinzufügen (Bereich: Benutzer).
